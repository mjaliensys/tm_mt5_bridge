# TradeMagic MT5 Bridge 0.12.2

- Concurrent agent launches exit quietly when another process already holds the agent singleton. The losing launch does not open the control registry, run reboot bootstrap or start workers. The winning agent still locks a new unattended Windows session before worker execution.
- Fixes the watcher/logon-task launch race: when its launched agent exits, the watcher first checks for an authenticated running agent with the configured installation, Windows user, session and executable. A verified winner is adopted without consuming the crash budget. A quiet exit without a peer receives a bounded 30-second startup grace, then counts as a failure.
- Lock-file permission/I/O failures remain distinct from lock contention and are not silently treated as successful duplicate launches. Existing recovery latches, identity checks, unresponsive-agent recovery and worker execution fences remain enforced.
