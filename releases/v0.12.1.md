# TradeMagic MT5 Bridge 0.12.1

- Journal/WAL/SHM access failures report a storage error and affected journal path instead of an unhandled startup traceback. Storage faults stop and pause only the affected profile and invalidate its validation.
- Settings > Repair journal access offers an explicit administrator repair for a stopped profile. Elevation must use the same trading Windows account and a protected installed Bridge. Existing ACL entries are retained and explicit access is added for that account on the selected profile directory and existing journal/WAL/SHM files.
- Repair refuses redirected/shared paths and files held for writing. It saves an audited database copy, including committed WAL data, and checks the copy's integrity. Original journal bytes are verified unchanged. Missing or corrupt databases are retained for review; no replacement journal, automatic restore or order resubmission is performed.
- Entries remain paused and validation stays cleared. Run Test connection to perform normal broker reconciliation before explicitly starting the profile. Other profiles continue running. Retained repair copies consume additional disk space; the repair does not delete them automatically.

Upgrade using Reuse existing configuration. This installer remains unsigned. No live-money trades were submitted during release preparation.
