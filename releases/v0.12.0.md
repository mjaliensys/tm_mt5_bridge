# TradeMagic MT5 Bridge 0.12.0

- Honors backend polling hints (1–60 seconds) and drains queued command batches promptly. Blocked workers cannot fast-drain; durable IDs, ownership, expiry, entry gates and outage backoff remain enforced.
- Suppresses redundant empty overlap uploads without advancing checkpoints ahead of pending acknowledgements. Empty backfill and incomplete-coverage markers are retained when they convey history coverage.
- Recognizes uniquely linked broker stop-out and manual/mobile/web pure exits. Reversals, scale-ins, same-side orders, symbol mismatches and ambiguous ownership remain conflicts.
- Recovers overlap history from the last acknowledged watermark after extended downtime, with a five-minute overlap and a fourteen-day catch-up bound. Existing Bridge history start and verified clock coverage remain enforced.
- Refreshes snapshots after mutations and history after closes/partial closes/bulk operations. Recovered errors clear by operation; successful reconciliation does not hide an outstanding history/reporting failure.
- Unknown broker-clock gaps remain explicit, including short weekday gaps with matching offsets. The installer does not infer historical time coverage from matching endpoint offsets or weekday assumptions. Verified configured intervals can still cover a gap and trigger history retries.

Upgrade using Reuse existing configuration. Existing account identity, journals and entry settings are preserved by the normal upgrade workflow; run Test connection for each profile before explicitly starting it. No live-money trades are submitted during release preparation. This installer remains unsigned.
