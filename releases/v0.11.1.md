# TradeMagic MT5 Bridge 0.11.1

- Corrects market-fill, position-volume and protection verification when MT5 doubles contain representation noise. Only differences within two floating-point ULPs are normalized; requested volumes and prices remain exact.
- Reconciles uncertain fills only from their persisted broker-returned tickets. Orders are never resent.
- Rechecks final market-opening protection failures only when original evidence proves a representation-only mismatch and fresh exact-ticket evidence verifies the same execution. A corrected result is appended; original results and evidence remain intact. Genuine mismatches and executions followed by position-management commands remain blocked for review.
- Existing local entry settings remain unchanged. After upgrading with Reuse existing configuration, test each profile before starting it. Keep entries paused until reconciliation is reviewed.
- Supports maintenance of 0.11.0 installations. Demo and Live account classification checks remain enforced.
